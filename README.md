# LearnOffline Web Starter
1. Cài Python 3.10+.
2. Mở terminal tại thư mục và chạy `python -m pip install -r requirements.txt`
3. Chạy `python -m streamlit run streamlit_app.py`
4. Để đưa lên web: tạo GitHub repository, tải lên 3 tệp này, vào https://share.streamlit.io, đăng nhập bằng GitHub, chọn Create app, repository, branch `main`, file `streamlit_app.py`, rồi Deploy.
Lưu ý: đây là demo. Lịch sử chỉ nằm trong phiên hiện tại; chưa có cơ sở dữ liệu bền vững/tài khoản. Bản web công khai cần Internet để truy cập. Để hoạt động offline cần phát triển thêm PWA/service worker hoặc giữ bản Windows.
